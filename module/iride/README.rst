Iride 6D
========

Firmware personalizzato per Canon EOS 6D: interfaccia a tutto schermo, animata.

- Astro: Via Lattea (NPF), intervallometro con preset, fuoco stelle (HFR),
  allineamento polare, calendario del cielo, etichetta dei file
- Foto: HDR, focus stacking, Dual ISO, ETTR, movimento e trappola di fuoco,
  strumenti del Live View, filtri ND con posa B
- Rullini: pellicole con push/pull, pausa, contatore nel Live View
- Profili personali e Torna alla 6D (ripristina tutto)

Si apre col cestino (dentro Iride il cestino porta al menu ML), col tasto
luce del display superiore o da Shoot, Iride.
